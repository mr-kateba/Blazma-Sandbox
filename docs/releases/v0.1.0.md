## Blazma Sandbox 0.1.0 — أول إصدار تجريبي

أداة لتحليل الملفات والملفات المضغوطة والروابط المشبوهة على Windows: تفحص الملف دون تشغيله، ثم تشغّله داخل بيئة معزولة تُحذف بعد الاستخدام، وتراقب ما يفعله، وتشرح النتيجة بالعربية مع الأدلة.

> **إصدار تجريبي مبكر.** المحلّل والتقارير ومحرك YARA مختبرة بأكثر من 800 اختبار آلي، لكن التشغيل الفعلي داخل Windows Sandbox والأجهزة الافتراضية لم يُجرَّب بعد على أجهزة كثيرة. جرّب أولًا «التحليل التجريبي» من الشاشة الرئيسية، وأخبرنا بأي مشكلة.

### التنزيل

| الملف | لمن |
|---|---|
| `BlazmaSandbox-0.1.0-setup.exe` | **أغلب الناس.** يثبّت لحسابك فقط، بدون صلاحيات المسؤول، وواجهته بالعربية |
| `BlazmaSandbox-0.1.0-win-x64-portable.zip` | نسخة محمولة: فك الضغط وشغّل `BlazmaSandbox.exe` |
| `SHA256SUMS.txt` | بصمات الملفات للتحقق من سلامتها |

البرنامج غير موقّع رقميًا بعد، فقد يظهر تحذير Windows SmartScreen: اختر **More info** ثم **Run anyway**.

### المتطلبات

- Windows 10 (الإصدار 1809 أو أحدث) أو Windows 11، 64 بت.
- لتحليل ملفات حقيقية: Windows **Pro أو Enterprise أو Education** مع تفعيل ميزة *Windows Sandbox*.
- على Windows **Home**: استخدم جهاز VirtualBox افتراضيًا (الخطوات في `docs/VIRTUAL-MACHINES.md`).
- التحليل التجريبي يعمل على أي جهاز دون أي إعداد.

### أهم ما فيه

- **تحليل دون تشغيل:** البصمات، وتفاصيل PE، وimphash، و95 قاعدة لقدرات الكود، والقيم المستخرجة (روابط، ومحافظ عملات رقمية، وتوكنات).
- **تشغيل معزول:** Windows Sandbox، أو جهاز VirtualBox أو Hyper-V يُسترجع من لقطة نظيفة.
- **إنترنت وهمي افتراضيًا:** لا شبكة حقيقية، ومع ذلك ترى ما حاول الملف تنزيله أو إرساله.
- **لقطات للشاشة ووضع تفاعلي**، وضغط أزرار المثبّتات تلقائيًا.
- **الملفات التي ينشئها البرنامج ومناطق الذاكرة المريبة** تُنسخ وتُحلَّل.
- **YARA مدمج** مع الوحدة `pe`، على الملف والملفات المُنشأة والذاكرة.
- **ملفات مضغوطة** (ZIP و7z وRAR) مع تجربة كلمات المرور الشائعة مثل `infected`، و**تحليل الروابط**.
- **تقارير:** واجهة بـ 15 تبويبًا، ومصفوفة ATT&CK، وتصدير HTML وPDF وJSON وSTIX وMISP وSigma وYARA.
- **اختياري:** فحص السمعة بالبصمة فقط (VirusTotal وMalwareBazaar)، وذكاء اصطناعي محلي على جهازك.
- **سطر أوامر** `blazma` للتحليل الآلي والجماعي، وخيار في قائمة الزر الأيمن.
- **عربي أولًا**، مع الإنجليزية كخيار.

### الأمان والخصوصية

الملف لا يعمل على جهازك أبدًا، ولا يُرفع أي ملف إلى أي مكان. الفحص عبر الإنترنت والذكاء الاصطناعي معطّلان حتى تفعّلهما. التفاصيل في `SECURITY.md`.

**المطوّر:** [mr-kateba](https://github.com/mr-kateba)

## Blazma Sandbox 0.1.0 — first preview release

Analyzes suspicious files, archives and web addresses on Windows: inspects a file without running it, runs it in a disposable isolated environment, watches what it does and explains the result with evidence. Arabic first, English available.

> **Early preview.** The analyzer, reports and YARA engine are covered by 800+ automated tests, but real runs inside Windows Sandbox and virtual machines have not yet been tried on many computers. Start with the built-in demo analysis and report any problem.

**Downloads:** `BlazmaSandbox-0.1.0-setup.exe` (recommended; per-user, no administrator rights), `BlazmaSandbox-0.1.0-win-x64-portable.zip`, and `SHA256SUMS.txt`. The program is not code-signed yet, so SmartScreen may warn: choose **More info**, then **Run anyway**.

**Requirements:** Windows 10 1809+ or Windows 11, 64-bit. Real analyses need Windows Pro/Enterprise/Education with *Windows Sandbox* enabled, or a VirtualBox VM on Windows Home (see `docs/VIRTUAL-MACHINES.en.md`).

**Developer:** [mr-kateba](https://github.com/mr-kateba)
