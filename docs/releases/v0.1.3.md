## Blazma Sandbox 0.1.3 — عناوين IP، فحص أدق، وواجهة مرتّبة

### عناوين IP التي يتصل بها البرنامج

- جدول جديد في تبويب «الشبكة»: **العناوين التي حاول البرنامج الوصول إليها**. لكل عنوان ومنفذ: النطاق، والعملية التي اتصلت، وعدد المحاولات، وكيف انتهت (تمّ الاتصال، أجاب الإنترنت الوهمي، فشل أو حُظر، محاولة دون رد، استُعلم عن الاسم فقط).
- صار الوكيل يسجّل **كل محاولة اتصال**، لا الاتصالات الناجحة فقط. فحتى حين يكون الإنترنت معطّلًا أو وهميًا، ترى العنوان الذي حاول البرنامج الوصول إليه.
- في وضع الإنترنت الوهمي يظهر اسم النطاق الحقيقي بدل 127.0.0.1.
- خيار جديد (معطّل افتراضيًا) في الإعدادات ← التكاملات: بعد التحليل، يبحث Blazma عن العناوين الحقيقية للنطاقات من جهازك عبر DNS مشفّر. لا يُرسل إلا اسم النطاق.
- العناوين تظهر أيضًا في تقارير HTML وPDF وJSON وفي المؤشرات المصدّرة.
- قاعدتان جديدتان: الاتصال بعنوان IP مباشرة دون البحث عن اسم، وتكرار المحاولة مع عنوان لا يرد.

### فحص أدق وأقل إنذارات خاطئة

- برامج التثبيت العادية (Inno Setup وNSIS وMSI وSquirrel) لم تعد تظهر كأنها خبيثة. حين يكون الملف موقّعًا أو برنامج تثبيت معروفًا، تُحتسب الأفعال المعتادة لبرامج التثبيت بوزن أقل، ويكتب التقرير السبب. وأي سلوك للتخفي يلغي هذا التخفيض فورًا.
  - مثال: برنامج تثبيت موقّع كان يأخذ 56 (خطورة مرتفعة)، وصار 19 (خطورة منخفضة). وبرنامج خبيث مخفي ما زال 100.
- قواعد جديدة:
  - سرقة كلمات المرور: نسخ ذاكرة LSASS، أو حفظ SAM من السجل، أو نسخ كلمات مرور المتصفح وملفات الارتباط.
  - تنزيل ملفات بأدوات Windows المدمجة (certutil وbitsadmin وregsvr32 وغيرها).
  - تجاوز UAC أو تعطيله.
  - رسائل الفدية في عدة مجلدات.
  - التنكّر باسم أحد برامج Windows (مثل svchost.exe) خارج مجلد Windows.
- تصفية أدق لنشاط Windows Sandbox نفسه.

### الواجهة

- رأس التقرير وصفحة «نظرة عامة» يتكيّفان مع الشاشات الصغيرة، فلا تتداخل الأزرار مع اسم الملف.
- أعمدة «السجل» صارت مرتبة ولا تتداخل.
- القيم التقنية (الأحجام والمسارات والأرقام) تظهر بترتيبها الصحيح داخل النص العربي.
- ترجمة عبارات كانت بالإنجليزية، وبطاقة «ذكاء اصطناعي محلي» تُظهر هل هو مفعّل.

## Blazma Sandbox 0.1.3 — IP addresses, sharper detection, tidier interface

**Network.** A new table in the Network tab lists every address and port the program tried to reach, with the domain, process, attempt count and outcome (connected, simulated internet, failed or blocked, no answer, name lookup only). The agent now records connection *attempts*, not only successful connections, so addresses show up even with the internet off or simulated; simulated mode shows real domain names instead of 127.0.0.1. An opt-in setting looks up the domains' current addresses from this computer over DNS-over-HTTPS (domain names only). Addresses are included in HTML, PDF and JSON reports and in exported indicators. New rules: direct IP contact without a name lookup, and repeated unanswered attempts.

**Detection.** Ordinary installers (Inno Setup, NSIS, MSI, Squirrel) are no longer scored like malware: for signed or recognised installers, typical installer behaviour counts for less and the report says why; any stealthy behaviour cancels the reduction. New rules for credential theft (LSASS dumps, SAM hive saves, browser logins and cookies), downloads through built-in Windows tools, UAC bypass, ransom notes and programs disguised as Windows components.

**Interface.** The report header and overview adapt to small windows, history columns stay aligned, technical values keep their order inside Arabic text, and remaining English phrases are translated.
